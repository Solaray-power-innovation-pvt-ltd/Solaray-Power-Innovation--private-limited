# Solaray Power Innovations Private Limited website

## Files
- `index.html` — website home page and sections
- `style.css` — responsive design for mobile and desktop
- `script.js` — mobile menu and WhatsApp enquiry form
- `assets/solaray-logo.jpg` — supplied company logo
- `assets/solaray-wordmark.jpg` — supplied company wordmark image

## Preview locally
Open `index.html` in a browser. For a local development server, run:
`python -m http.server 8000`
Then open `http://localhost:8000`.

## Publish free on GitHub Pages
1. Create a GitHub repository named `solaray-power-innovation` (or use your existing repository).
2. Upload all files and the `assets` folder, keeping the folder structure.
3. In repository Settings → Pages, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
4. Your project URL will typically be `https://YOUR-USERNAME.github.io/solaray-power-innovation/`.

## Before publishing
- Confirm the company phone numbers, address, working hours and legal company details.
- Only add claims such as MNRE/TSECL authorization or empanelment if you have current official documents confirming them.
- The contact form opens WhatsApp; it does not save submissions to a server.
- For a custom `.com` domain, you must register the domain separately (normally paid); GitHub Pages hosting is free.
